# 📱 Travel Budget — 여행 예산 관리 앱

여행 가서 **하루하루 지출을 빠르게 기록하고, 예산 대비 얼마나 쓰고 있는지 실시간으로 확인**하는 모바일 중심 웹앱입니다. React + Vite로 만들어졌고, 데이터는 **브라우저 localStorage에 자동 저장**되며, **백업 파일로 내보내기/복원**도 가능합니다 (서버·로그인 없음).

## 주요 기능

| 기능 | 설명 |
|------|------|
| **초기 설정** | 여행 일수(1~60일), 하루 평균 예산, 통화를 입력하면 총예산 자동 계산 (예: `120 × 11일 = 1,320`) |
| **2가지 기록 방식** | 💳 **총액만** — 하루 지출을 숫자 하나로 / 📋 **항목별** — 외식·교통·관광·쇼핑 등 카테고리별 기록 |
| **카테고리 관리** | 기본 4개, 직접 추가/삭제 (최대 7개), 항목별 예산 배분 설정 |
| **빠른 입력** | 항목명 + 금액 입력 후 저장 시 토스트(`✓ 외식 12,000€`)로 즉시 피드백 |
| **실시간 잔여/누적** | 사용액, 잔여 예산, 그날까지 "누적 ± 차이"(여유/초과) 표시 |
| **전체 일정 요약** | 여행 전체 총지출과 일자별 현황 한눈에 |
| **데이터 백업** 🆕 | **💾 저장** 버튼으로 전체 데이터를 백업 파일로 보관 (기기 분실·캐시 삭제 대비) |
| **데이터 복원** 🆕 | **가져오기**로 백업 파일에서 데이터 되살리기 |
| **다국어 / 다중 통화** | 6개 언어(🇰🇷🇺🇸🇯🇵🇨🇳🇪🇸🇫🇷), 15종 통화 |
| **자동 저장** | 입력 즉시 localStorage 저장, 앱 열면 자동 로드 |

## 사용법

1. **시작 화면**에서 여행 일수 · 하루 예산 · 통화 · 기록 방식 · 언어 입력 후 **`시작하기 →`**
2. **트래커 화면**에서 날짜(Day) 선택 → 그날 쓴 돈 입력
   - *총액만* 모드: 하루 지출 숫자 하나
   - *항목별* 모드: 카테고리별 `항목명 + 금액` 추가
3. 상단에서 **잔여 예산**과 **누적 ±(여유/초과)** 확인
4. **지출 입력을 마치면 화면 하단의 💾 저장 버튼을 한 번씩 눌러 백업** (아래 상세 설명)

## 데이터 백업 / 복원 (데이터 유실 방지) 🆕

> 💡 **왜 필요한가:** 데이터는 이 기기의 브라우저에만 저장됩니다. 캐시 삭제·기기 분실·시크릿 모드 시 사라질 수 있어, 백업 파일을 따로 보관하면 안전합니다.

### 백업하기 (💾 저장)

1. 지출 입력을 마친 뒤, 화면 **하단에 항상 떠 있는 `💾 저장` 버튼**을 누름
2. **모바일** → 공유 시트가 뜸 → **카톡 '나에게 보내기' / 메일 / 파일 앱** 등으로 백업 파일 저장
   **PC** → 백업 파일(`여행예산_백업_2026-06-26.json`)이 자동 다운로드
3. 토스트로 완료 안내
4. 🔔 백업 안 한 변경이 있으면 버튼에 **빨간 점**이 뜨고 안내문이 *"아직 백업되지 않았어요"*로 바뀌니, 그때 눌러주면 됨

### 복원하기 (가져오기)

1. 새 기기/브라우저에서 앱을 열고 **`가져오기`** 버튼 클릭
2. 보관해 둔 백업 `.json` 파일 선택
3. **확인 모달**(백업 시점 표시 + 덮어쓰기 경고) → `복원` 누르면 데이터 복구

> **Tip:** 여행 중 하루 입력이 끝날 때마다 `💾 저장` → 카톡 '나에게 보내기'로 보내두면, 폰을 잃어버려도 그대로 되살릴 수 있어요.

### 백업 파일 포맷

```json
{
  "app": "travel-budget",
  "schema": 1,
  "exportedAt": "2026-06-26T12:00:00.000Z",
  "config": { "tripDays": 11, "dailyBudget": 120, "currency": "EUR", "mode": "preset", "cats": [], "lang": "ko" },
  "days": {
    "tbv3-days-11-EUR": { "savedCats": [], "savedDays": [] }
  }
}
```

- `schema` 버전으로 향후 데이터 구조가 바뀌어도 복원 호환성 확보
- 가져오기 시 `app` 필드를 검증하여 다른 앱의 파일은 거부

## 동작 방식 (기술 메모)

- **저장 위치:** `localStorage`
  - `tbv3-config` — 여행 설정(일수·예산·통화·모드·카테고리·언어)
  - `tbv3-days-{일수}-{통화}` — 날짜별 지출 데이터
  - `tbv3-notice-seen` — 첫 방문 안내 표시 여부
- **백업/복원:** 위 키들을 하나의 JSON으로 묶어 내보내기 / 가져오기
- **모바일 공유:** `navigator.share`(Web Share API)로 파일 공유, 미지원 환경(주로 PC)에서는 다운로드로 자동 폴백

## 참고 / 한계

- **앱 열 때 자동 가져오기는 불가** — 브라우저 보안상 사용자가 파일을 직접 선택해야 함. 단, 평소엔 localStorage가 열자마자 자동 로드되어 로딩 지연은 없음
- **기기 간 자동 동기화 없음** — 백업 파일을 수동으로 옮겨야 함
- **모바일 공유 기능은 HTTPS/localhost에서만** 동작 (배포 후 폰에서 확인 권장)

## 개발 / 실행

```bash
cd travel-budget
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 프로덕션 빌드 (dist/)
```

> Windows PowerShell에서 실행 정책 오류가 나면 `npm.cmd run dev` 사용.
